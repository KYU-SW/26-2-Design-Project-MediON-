## AI 채혈튜브 자동 검수 시스템

**대상:** 임상병리사 / 채혈 담당 의료진 / 병원 검사실

**핵심 문제:**
혈액검사에서는 검사 장비의 정확성뿐만 아니라, 검사 전에 채혈튜브가 올바르게 준비되었는지가 중요함.

검사실에서는 채혈된 검체를 확인할 때

* 적절한 종류의 채혈튜브를 사용했는지
* 필요한 만큼 혈액이 채워졌는지
* 라벨이 제대로 부착되어 있는지

등을 확인해야 함.

하지만 검체 수가 많아질수록 사람이 모든 튜브를 반복적으로 육안 확인해야 하고, 검체량 부족이나 라벨 누락 등의 문제가 검사 전에 발견되지 않으면 재채혈이나 검사 지연으로 이어질 수 있음.

일반적인 검사 과정이

“채혈된 검체를 사람이 직접 확인한다.”

라면, 이 시스템은 조금 다름.

**“카메라에 채혈튜브를 보여주면 AI가 검사 전 확인사항을 자동으로 검수한다.”**

가 핵심이야.

예를 들어 정상적인 채혈튜브가

보라색 튜브
혈액량 적정
라벨 부착 완료

상태라고 해보자.

AI가 카메라 영상을 분석해서,

**검체 자동 검수 결과**

🟣 튜브 종류: Purple Cap 확인
🩸 혈액 충전 상태: 적정
🏷 라벨: 정상적으로 부착됨

**최종 결과: 🟢 검사 진행 가능**

으로 보여주는 거야.

반대로 문제가 있는 검체가

파란색 튜브
혈액량 부족
라벨 부착 완료

상태라면,

AI가

**검체 자동 검수 결과**

🔵 튜브 종류: Blue Cap 확인
🩸 혈액 충전 상태: 부족 ⚠️
🏷 라벨: 정상적으로 부착됨

**최종 결과: 🔴 검체 확인 필요**

**확인 사항: 채혈량 부족**

처럼 보여주는 거야.

### AI가 확인하는 항목

**1. 채혈튜브 종류 확인**
카메라 영상에서 튜브 뚜껑을 인식하여 파란색, 보라색, 노란색 등 튜브 종류를 분류함.

**2. 혈액 충전 상태 확인**
튜브 내부의 혈액 영역을 AI가 탐지하여 적정량이 채워졌는지, 부족한지를 판단함.

**3. 라벨 부착 여부 확인**
튜브에 검체 라벨이 존재하는지 자동으로 탐지함.

### 전체 동작 과정

채혈튜브
↓
카메라 촬영
↓
AI 객체탐지
↓
튜브 종류 / 혈액량 / 라벨 확인
↓
검수 결과 제공

**정상 검체 → 🟢 검사 진행 가능**

**이상 검체 → 🔴 검체 확인 필요**

### 이 시스템을 설계하는 이유

혈액검사 과정에서는 검체량 부족, 잘못된 튜브 사용, 라벨 문제 등 검사 전 단계에서 여러 오류가 발생할 수 있음.

이러한 문제는 검사실에서 다시 검체를 확인하거나 환자에게 재채혈을 요청하게 만들 수 있고, 결과적으로 검사 결과가 늦어질 수 있음.

따라서 채혈튜브가 검사실에 들어왔을 때 AI가 기본적인 검수 항목을 자동으로 확인하여, 문제가 있는 검체를 검사 전에 빠르게 선별하는 시스템을 설계하고자 함.

### 사용 AI

YOLO 기반 Object Detection을 이용하여 채혈튜브 이미지에서

* 튜브 뚜껑
* 혈액 영역
* 라벨

을 자동으로 탐지함.

AI가 탐지한 결과를 이용하여 최종적으로

**검사 가능 / 확인 필요**

두 상태로 사용자에게 보여줌.

### 사용 데이터셋

공개된 채혈튜브 이미지 데이터셋을 사용하여 AI를 학습함.

데이터에는

* 정상 혈액량
* 부족한 혈액량
* 라벨
* 파란색 뚜껑
* 보라색 뚜껑
* 노란색 뚜껑

등의 라벨이 포함되어 있어 채혈튜브 자동 검수 모델 학습에 활용할 수 있음.

### 핵심 차별점

일반적인 의료 AI가

“환자의 질병을 예측하거나 진단한다.”

에 초점을 맞춘다면,

이 시스템은

**“혈액검사를 하기 전에 검체 자체에 문제가 없는지 AI가 먼저 확인한다.”**

는 점에서 차이가 있음.

AI가 검사실 직원을 대신하는 것이 아니라, 반복적으로 이루어지는 검체 확인 작업을 보조하고 문제가 있는 검체를 우선적으로 확인할 수 있도록 하는 것이 목적임.
